How Unbiased Random Selection Works

Every value inside an inclusive range [Min, Max] should have an identical probability of being selected. CalcMaster uses the browser's built-in window.crypto.getRandomValues generator paired with rejection sampling in integer mode to avoid the modulo bias found in naive random formulas.

Uniform Integer = Min + floor(u × (Max − Min + 1)), where u ∈ [0, 1)

Step-by-Step Instructions

  1. Enter your inclusive Minimum and Maximum boundaries.
  2. Choose how many numbers to generate (from 1 up to 100) and pick Whole Numbers or Decimals.
  3. Check Unique values only if duplicates must be excluded (for instance, raffle tickets or classroom teams), then click Generate Numbers.

Practical Examples

1. Classroom Raffle Draw (Unique Integers): With 30 students numbered 1 to 30, set Min = 1, Max = 30, Quantity = 3, and check Unique values only to pick 3 distinct prize winners.

2. Dice & Board Game Rolls (Repeats Allowed): Set Min = 1, Max = 6, Quantity = 2, leave Unique unchecked, and press Generate Numbers to simulate rolling two six-sided dice where doubles like 4, 4 can appear.
